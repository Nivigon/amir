Amir: King of Africa · voorstel 2

Talentgrid van Amir

Vijf rijen per boom. Per rij kies je één talent, net als in het grid van Warcraft: soms uit drie, soms uit twee, en een enkele rij heeft er één die je gewoon neemt. De bovenste rij opent de volgende. Onderin de mega. Gekozen op bouwbaarheid: bijna alles is een getal in TRIBE_CONFIG of een regel op een haakje dat al bestaat.

Klik om te kiezen, zoals een speler dat zou doen. Klein: een getalMidden: een paar regels op een bestaand haakjeGroot: nieuw stuk code of beeld

Zo bouw je het grid

De boom die er nu staat is een rij van drie talents waarbij elk talent het vorige vraagt (tbStaat). Een keuze per rij is daar een klein stapje vanaf: elk talent krijgt een veld rij, en talents met dezelfde rij sluiten elkaar uit. Alles wat een talent doet blijft via tribeHeeft en abilityWaarde lopen, dus daar verandert niets.

1. Een rij in TRIBE_CONFIG

Elk talent krijgt rij (1 tot 5). Talents met dezelfde rij zijn de keuzes; de volgorde in de lijst is links naar rechts.

{ id: 'low_sweep', naam: 'Twin Sweep', rij: 1, ladingen: 2, ... },
{ id: 'thorn_breaker', naam: 'Thorn Breaker', rij: 1, treffers: 1 },
{ id: 'quick_hand', naam: 'Quick Hand', rij: 2, herstelTempo: 1.6 },

2. tbStaat kent een rij

Een nieuwe stand af: in deze rij is al iets anders gekozen.

function tbStaat(t, i){
  const r = tbRun(), a = tbLijst(t)[i];
  if (t.locked || a.leeg) return 'dicht';
  const heeft = b => r.abilities.includes(b.id);
  if (heeft(a)) return 'geleerd';
  const rij = n => t.abilities.filter(b => b.rij === n);
  if (rij(a.rij).some(heeft)) return 'af';
  if (a.rij > 1 && !rij(a.rij - 1).some(heeft)) return 'dicht';
  return r.punten > 0 ? 'open' : 'wacht';
}

3. Een punt per rij

tribeNaLevel telt niet meer talents maar rijen. En Het Pad telt mee, want het deelt de punten.

4. De boom tekent rijen

tribeBoomToon maakt per rij één .tbrij met daarin een, twee of drie .tbknoop. De ring, de schacht en de klauwen blijven zoals ze zijn; de lijn gloeit op boven een rij waarin iets gekozen is. TB_ROMEINS heeft er al vijf.

5. Het Pad is een vierde tribe

Een blok in TRIBE_CONFIG.tribes met algemeen: true: niet op het keuzescherm, wel in de boom als tweede tabblad. Zijn talents gaan in dezelfde RUN.abilities, dus tribeHeeft werkt meteen. Eén pot punten: de speler kiest per level of hij in zijn stam of in het pad investeert.

6. Wisselen

Warcraft laat je je keuze terugdraaien. Hier kan dat met een knop in de pauze: RUN.abilities leeg en de punten terug. Eén regel werk; wanneer het mag (altijd, of alleen in het dorp) is een keuze voor later.

Bouwvolgorde als je gelijk wilt beginnen

  1. Het grid zelf (stap 1 tot 4) met alleen de negen talents die er al zijn, in hun nieuwe rijen. Dan speel je meteen met keuzes.
  2. Alle talents met het label klein: een getal in TRIBE_CONFIG en een abilityWaarde op de plek die het getal al gebruikt.
  3. Het Pad als vierde tribe (stap 5).
  4. De talents met het label midden, per stuk met knoppen in de sandbox (sbAbilities), en Test 14 om te kiezen.
